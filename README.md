# Desktop Doodle 🎨🖌️
**Version 0.1 – Your always-on-top sketchpad**

**Desktop Doodle** is a lightweight, floating, always‑on‑top sketchpad for Windows.  
Draw, erase, type text (it now supports RTL languages too), and edit images with a clean, custom‑styled interface.  
Designed for quick notes, annotations, mockups, or just doodling over your desktop.

Desktop doodle works in two modes:
 - **Freehand**: just click and drag as always.
 - **Straight line**: hold `Shift` while dragging. You'll see a dashed preview, and when you release, a solid straight line is drawn from the start point to the end point.
 - This feature works with both Pen and Eraser.

## ✨ Features

- **Floating & Always‑on‑Top** – Never lose your sketch behind other apps.  
- **Drawing Tools** – Pen (adjustable width), Eraser, Text with font and rotation.  
  *All tools support opacity control (0–100%) for soft blending and ghostly effects.*  
- **Opacity Control** – A dedicated slider lets you set the transparency of the pen, text, and bucket fill independently of the colour.  
- **Flood Fill** – Lightning‑fast bucket fill with full alpha support.  
- **Color Picker** – Left‑click for pen colour, right‑click for background colour.  
- **Selection & Editing** – Select, move, resize, rotate, flip, cut, copy, paste.  
- **Undo/Redo** – Full history (up to 20 steps).  
- **Zoom & Grid** – Zoom in/out, toggle‑able pixel grid.  
- **Canvas Sizing** – Preset sizes (Full HD, HD, A4, A3, etc.) or custom dimensions.  
- **File Support** – Save as PNG, JPEG, BMP; load images and annotate.  
- **System Tray** – Minimise to tray and restore with a double‑click.  
- **Custom Cursors** – Unique pen, eraser, and eyedropper cursors.  
- **Keyboard Shortcuts** – `Ctrl+Z/Y`, `Ctrl+C/X/V`, `Shift` for straight lines, `Ctrl+Arrows` for rotation.  
- **Beautiful Gray Border** – Gives you room to draw right to the edge.


## 🖥️ Usage

- **Move the window** – drag the title bar.
- **Resize** – drag the bottom‑right corner grip.
- **Hide** – click the ✕ button (app minimises to system tray).
- **Show** – double‑click the tray icon or use the tray menu.

### Drawing

- Select a tool from the toolbar (Pen, Eraser, Text, Select).
- Click and drag on the canvas.
- For **text**: click where you want the text, type, and press `Enter` (or `Shift+Enter` for new lines). Move/resize the text box using the grip in the bottom‑right corner.

### Selection

- Use the **Select** tool to drag a rectangle.
- Use **Cut** / **Copy** / **Paste** to modify the selection.
- Drag the selected area to move it.

### Keyboard Shortcuts

| Shortcut            | Action                         |
|---------------------|--------------------------------|
| `Ctrl+Z`            | Undo                           |
| `Ctrl+Y`            | Redo                           |
| `Ctrl+C`            | Copy selection                 |
| `Ctrl+X`            | Cut selection                  |
| `Ctrl+V`            | Paste (then click to place)    |
| `Ctrl+→` / `Ctrl+←` | Rotate selection ±5°           |
| `Ctrl+R`            | Rotate selection 90° clockwise |
| `Shift` + drag      | Draw straight line|
| `Enter` | Commit text (when typing) |
| `Esc`   | Cancel text input |

| Keys | Action |
